# Abstract Draft

## English

Ground vehicles on rough terrain need paths that reach a goal while avoiding impassable ground, rollover-prone terrain, and overly sharp turns. Learning-based generators are fast, but directly predicting all path coordinates leaves start and goal positions and headings to learning, while imitation alone does not explicitly optimize terrain-dependent physical requirements. We propose **Path MeanFlow** with two main designs. First, a boundary-aligned trajectory representation analytically embeds the start and goal positions and headings in a spline decoder, so the network predicts only the route between them. Second, the generator learns long-range route structure from expert paths before undergoing **privileged multi-objective terrain adaptation (PMTA)**, which coordinates gradients for planning-region violation, rollover stability, and curvature. During learning, complete terrain is used only by the stability objective. To condition generation on current terrain evidence, a mask marks observed cells that may support the vehicle center; unknown and forbidden cells are unavailable. At deployment, Path MeanFlow uses only this masked observation and generates one path in a single forward pass, without online physical-cost evaluation or trajectory optimization. ## 中文

在野外崎岖地形中，无人车需要根据当前获得的地形信息，快速规划一条通往目标的全局路径，同时避开不可通行或容易导致倾覆的区域，并满足车辆的转向限制。搜索和优化方法通常需要在规划过程中不断检查并调整路径，直到路径满足上述要求，因此会产生较大的在线计算开销。学习式生成器能够直接从观测产生路径，避免部署时的迭代求解。然而，模仿学习主要通过生成轨迹与专家轨迹之间的相似程度来提供监督，生成路径的物理可行性只能被间接学习。另一方面，将起终点位姿作为网络条件并不能约束输出空间；如果直接生成无约束的路径坐标，边界是否满足仍然取决于预测误差。为此，我们提出 Path MeanFlow，分别改进路径表示与训练过程。Path MeanFlow 将规划任务变换到统一坐标系，并采用边界约束 B 样条将起终点位置和朝向解析写入解码器。网络仅预测控制路径内部形状的自由坐标，其输出经过解码后即满足给定边界。该样条表示还提供连续的路径几何量，用于在训练中计算地形相关的物理目标。Path MeanFlow 采用两阶段训练：第一阶段从专家示范中学习全局路线结构，第二阶段直接根据生成路径的多项物理目标调整模型，并协调这些目标之间相互冲突的梯度。完整地形仅用于训练阶段的稳定性监督。训练完成后，模型只需使用当前地形观测，通过一次前向生成路径，无需在部署时计算物理代价或执行轨迹优化。实验表明，相比依赖在线迭代的方法，Path MeanFlow 在一定的可行性差异下显著降低了规划延迟，在路径可行性与计算效率之间取得了更适合频繁重规划的折中。
