# 第一步：研究定位底稿

本文档只回答 2026-08-10 会议中首先需要澄清的四个问题，作为后续 Pipeline、Abstract、
Method 和 Experiments 的共同依据。它不是论文正文。

## 1. 这项工作到底解决什么问题？

**面向普通机器人审稿人的一句话：** 本文研究如何在减少在线规划计算的同时，为崎岖
地形上的无人地面车辆生成兼顾当前规划支撑、倾覆风险和转向能力的全局参考路径。

会议中所说的“让无人车走得更稳”是应用目的，不是可以直接写入结论的实验事实。在
论文中，它应被拆成可评价的路径性质：规划区域通过、稳定性通过、曲率通过及三者的
联合可行性；真机实验再观察任务成功、车辆姿态和跟踪表现。

这里的目标不是在稳定性上无条件超过所有规划器。充分迭代的逐实例方法可能获得更高的
可行性或稳定性，同时通常需要更多实例级计算；实际延迟差异必须由实验测量。本文真正
研究的是：能否把重复的物理代价计算转移到训练阶段，使部署端以较低在线开销生成能够
通过预设物理阈值的路径。因此，论文需要呈现的是可行性与规划开销之间的权衡，而不是
宣称 Path MeanFlow 在每个指标上都最好。

本文的直接输出是二维全局几何参考路径，而不是带时间的控制轨迹。无人机和渐进式建图
只负责提供上游地形观测，路径跟踪和短时响应由下游模块完成。因此，这不是一篇端到端
无人机建图到无人车控制的系统论文，也不应把“硬安全保证”作为问题定义的一部分。

## 2. 采用什么技术路线？

**一句话：** 使用条件生成网络，根据当前可用的地形观测和给定的起终点位姿，直接生成
一条 B-spline 全局参考路径；先从专家路径学习长距离路线结构，再利用训练阶段的三项
可微物理目标，使生成器适应规划区域、倾覆稳定性和曲率要求。其中，完整地形只用于
稳定性目标和离线审计，规划区域违反由 mask 计算，曲率违反由路径几何计算。

具体链路为：

1. 显式 mask 告诉网络当前哪些地形单元已经观测且允许车辆中心进入；
2. 边界对齐的 B-spline 表示解析固定起终点位置与朝向，网络只生成内部路线；
3. 第一阶段 ERPL 从专家路径学习全局绕行结构；
4. 第二阶段 PMTA 分别保留规划区域违反、稳定性违反和曲率违反目标，并协调它们可能
   冲突的梯度；
5. 部署时只使用部分地形观测、mask、起终点位姿和一个随机源，一次前向生成一条路径，
   不访问完整地形，不计算在线物理代价，也不执行在线轨迹优化或多路径筛选。

这里不能笼统称为“端到端导航”。更准确的表述是“学习式全局路径生成”，因为感知建图、
路径生成和局部执行仍有清楚的系统边界。

PMTA 在训练阶段仍然显式计算物理代价，并将这些代价对生成路径的梯度反向传播到网络
参数。所谓“cost amortization”是指：采用逐实例代价引导或轨迹优化的方法在每个新规划
实例上重新评价代价并迭代更新路径，而 PMTA 在多个训练地形上预先学习“观测到低代价
路径”的映射，部署时复用这个映射。因此被消除的是**部署阶段**的显式 cost evaluation
和迭代优化，不是训练阶段的物理建模。摊销生成是逐实例优化的近似替代，不天然保证达到
在线优化器的最终稳定性。

## 3. 最接近的工作是什么？

### 3.1 方法路线上的主要参照：Motion Planning Diffusion

基于当前检索和会议中展示的论文，Motion Planning Diffusion（MPD）是最接近的生成式
运动规划参照。MPD 用扩散模型学习轨迹分布先验，以 B-spline 控制点作为低维轨迹表示，
并在多步去噪过程中结合任务代价梯度。它与本文共享“从数据学习路线分布、在样条空间
生成路径”的总体路线，因此比 Hybrid A* 更适合作为回答“最接近的工作是什么”的主线。

本文与 MPD 的预期区别不是简单地把 diffusion 换成 MeanFlow，而是两点组合：

- 用边界对齐的生成坐标解析固定起终点位置和朝向；
- 通过第二阶段训练将崎岖地形物理代价摊销到单步生成器参数中，而不是在部署时用代价
  梯度继续修正路径。

因此需要实验检验的实际价值是：相较于 MPD 式多步生成和在线代价引导，Path MeanFlow
能否用更少的在线计算获得可接受的联合可行性。现阶段不能先写成“更快且更安全”，也
不要求其稳定性无条件超过充分迭代的优化器。

### 3.2 问题领域上的参照：CAP 与 Uneven Planner

Capsizing-Aware Planner（CAP）和 Uneven Planner 更接近本文所处理的崎岖地形物理
问题。CAP 把倾覆稳定性形成的可通行朝向纳入图优化；Uneven Planner 通过 terrain pose
mapping 建模地形与车体状态的耦合，并用数值优化求解轨迹。它们适合说明为什么崎岖
地形规划必须考虑车辆姿态、稳定性和曲率，也适合作为优化式实验基线。

需要保持如下层级：

| 角色 | 工作 | 与本文的关系 |
|---|---|---|
| 主要方法参照 | MPD | 最接近生成式路线：学习轨迹先验、样条表示、代价引导 |
| 崎岖地形参照 | CAP、Uneven Planner | 最接近地形稳定性建模，但采用图优化或数值优化 |
| 实验基线族 | Hybrid A* | 搜索式比较对象，不是本文最接近的学习式工作 |
| 基础生成模型 | MeanFlow | 本文采用的单步生成基础，不是崎岖地形规划竞品 |

这一定义是当前论文叙事的主锚点，不等同于已经完成完整 related-work novelty survey。
尤其是“边界对齐轨迹表示是否首次提出”仍需在正式 Related Work 阶段做更广泛检索后再
下结论。

### 3.3 不同方法需要回答不同的比较问题

总体结果表可以统一报告指标，但论文不能据此形成一个不分条件的总排名。每类比较应有
独立的问题和结论边界：

| 比较对象 | 该比较回答什么问题 | 主要观察量 | 合理的结论边界 |
|---|---|---|---|
| 搜索式方法，如 Hybrid A* | 学习式生成能否以更低调用开销给出可用的全局路线 | 规划成功、延迟、路径长度、基本可行性 | 不把缺少高保真稳定性代价的搜索器当作稳定性上界 |
| 优化式方法，如 CAP、Uneven Planner | 省去逐实例物理代价优化后付出了多少可行性代价 | 联合及分项可行性、延迟、迭代次数、cost evaluations | 允许优化器更稳；重点报告计算开销与可行性的权衡 |
| 生成式方法，如 MPD | 单步摊销生成相对多步去噪和在线代价引导是否减少推理开销 | 联合可行性、p95 延迟、NFE、在线 cost/gradient 次数 | 这是最接近的机制对比，应匹配观测、数据和调参预算 |
| ERPL 与 PMTA | 第二阶段是否把物理目标真正吸收到生成器参数中 | PMTA 前后状态转移、分项可行性、路线漂移、部署开销 | 这是检验物理监督是否进入生成器参数的核心内部证据 |
| 显式在线 cost 优化 reference | 摊销生成与逐实例充分优化之间还剩多少经验差距 | 最终物理代价、可行性、运行时间及 cost/gradient evaluations | 作为 privileged online-optimization reference，不作为形式化上界或公平总排名对象 |

ERPL 与 PMTA 的差异只能说明训练期物理监督是否改变了部署生成器。评价 cost
amortization 还必须结合显式在线优化 reference 的质量、cost/gradient evaluations 和
运行时间。如果该 reference 使用完整地形而 Path MeanFlow 只使用部分观测，两者差距
同时包含信息差距与摊销差距，不能全部归因于单步生成；只有观测信息一致的在线优化对照
才能更直接地隔离 amortization gap。

由此，Path MeanFlow 的主要胜负条件不是“比所有方法更稳”，而是以下组合是否成立：

1. 相比 ERPL，PMTA 在不增加部署期 cost evaluation 的情况下改善物理可行性；
2. 相比多步生成或在线优化方法，显著减少 NFE、cost/gradient evaluations 和规划延迟；
3. 上述效率收益对应的可行性损失被如实量化，而不是被总体平均数掩盖。

## 4. 两项核心创新是什么？

### 4.1 面向任务边界的轨迹表征

起终点位置和朝向已经由规划任务给定，不应让网络通过数据再次猜测。本文将这些已知
几何量解析写入 boundary-aligned B-spline decoder，使生成变量只描述未知的内部路线。
这一设计提供的是端点位置与一阶方向的结构保证。它是否改善训练稳定性或路径质量，
必须由表征消融验证，不能仅由解析构造推出。

### 4.2 将崎岖地形物理代价摊销到生成器的二阶段训练

第一阶段 ERPL 学习专家路径中的长距离路线结构；第二阶段 PMTA 在部署 endpoint 上
适配规划区域、倾覆稳定性和曲率三项目标，并用 MGDA 协调可能冲突的梯度。其中，只有
稳定性目标使用训练期完整地形提供的特权监督。这个阶段的首要作用，是把原本需要在每个
规划实例中显式计算并迭代降低的物理代价，转化为生成器参数中的训练期监督；MGDA 用于
处理这一摊销训练中的多目标梯度冲突。这里的创新主张是“路线学习与特权多目标 cost
amortization 的二阶段组合及其单步部署边界”，不是 MGDA 算法本身。完整地形始终不进入
部署模型输入。

## 5. 不列为核心创新的内容

- mask 是适配不规则有效观测区域所必需的支撑设计，但不是核心创新；
- 网络骨干是实现载体，不作为架构创新；
- 一次前向、无在线优化是二阶段 cost amortization 的部署价值，但不单列为第三项创新；
- 无人机前沿建图只是当前系统中的观测来源，不是论文主线。

## 6. 后续写作必须统一使用的四句回答

1. **做什么：** 在减少在线规划计算的同时，为崎岖地形无人车生成兼顾规划支撑、倾覆
   风险和转向能力的全局参考路径。
2. **怎么做：** 用条件 Path MeanFlow 从当前地形观测直接生成边界满足的 B-spline
   路径，并通过专家路线学习和特权多目标地形适配完成二阶段训练。
3. **最接近谁：** 方法路线最接近 MPD，地形物理问题最接近 CAP 和 Uneven Planner；
   Hybrid A* 是实验基线而不是最近邻工作。
4. **创新在哪：** 一是解析满足起终点位置与朝向的轨迹表征，二是将多项地形物理代价
   摊销到单步生成器、同时协调其梯度冲突的二阶段训练。
